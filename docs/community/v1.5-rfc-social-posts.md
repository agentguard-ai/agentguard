## LinkedIn Post

---

We just published our RFC for TealTiger v1.5 — and it's our biggest scope shift yet.

TealTiger started as a governance SDK. v1.5 turns it into a full Agent Development Lifecycle (ADLC) platform.

Build → Test → Deploy → Monitor → Iterate → Govern

Here's what we're proposing:

🧪 TEST
• Governance eval datasets — auto-harvest production denials as regression tests
• Multi-turn simulation — test governance across full agent conversations, not just single calls

🔄 ITERATE
• Policy A/B testing — split traffic between two policy versions, compare outcomes with data
• Production-to-eval loop — continuous pipeline from production anomalies to CI/CD gates

🏗️ BUILD
• Prompt & context governance — defend against injection and poisoning BEFORE the LLM sees it
• No-code policy builder — compliance officers create policies without writing code

🏛️ GOVERN
• Agent registry — one screen showing all governed agents across your fleet
• Sandbox governance — govern code execution inside Daytona, E2B, Docker

📊 MONITOR
• Native trace viewer — end-to-end governance traces without external dependencies
• User feedback API — link satisfaction data to governance decisions

All of this stays deterministic. No LLM in the governance path. Open source. Apache 2.0.

We're looking for feedback:
→ Which features would you use first?
→ What's missing?
→ Where should we prioritize simplicity over power?

RFC is live on GitHub: https://github.com/agentguard-ai/tealtiger/issues

If you're building agents in production — we'd love your input.
